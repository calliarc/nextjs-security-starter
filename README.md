# Next.js Security Starter

Next.js template with secure headers, rate limiting, CSRF protection and auth set up correctly.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Status: in development](https://img.shields.io/badge/status-in%20development-orange)

> **Status:** in active development. Star or watch the repo to follow progress.

## Features

- Strict Content-Security-Policy with nonces
- Security headers configured in one place
- Authentication with secure session cookies
- CSRF protection for server actions and API routes
- Rate limiting for login and API endpoints
- Input validation with Zod and safe error handling
- Dependency and secret scanning in CI

## Tech stack

- Next.js (App Router)
- TypeScript
- Auth.js
- Zod
- Middleware-based rate limiting
